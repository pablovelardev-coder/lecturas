# Lecturas

Página de ligas ("link in bio") de Pablo Velarde para Instagram: https://pablovelardev-coder.github.io/lecturas/

Para agregar una lectura, se suma un objeto a `lecturas.json` (`fecha`, `titulo`, `dato`, `fuente`, `url`) y se hace push. La página ordena por fecha, la más reciente arriba.

**Repo público:** aquí solo va lo que ya se publicó en Instagram. Nada de clientes, cifras internas ni datos personales.
